# Completeness is a reading, not a count

A phase has complete question coverage when its accepted artifacts, taken
together, answer or explicitly dismiss every question its catalog owns. Each
artifact must also contain no open decision before it can be accepted. A skill
establishes those conditions by reading the catalog and every artifact in the
phase together, not through labels, counts, or a second coverage registry.

Literal question names could make coverage countable but would constrain the
document while proving only that a label exists, not that an answer does.
Phase acceptance therefore reports the question-to-artifact-and-passage mapping
for review without persisting it; a wrong reading remains an accepted risk.
